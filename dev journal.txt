Plan

Host RAG model on a self healing kubernetes cluster. Terraform will be used to script the provisioning of cloud resources, but 
all of that will come way way later. Playing round with models and with the oprn telemetry demo first is where i start.

This project will aim to provide an effective application support engineer AI, retrieving and analysing data from various 
sources to determine and generate a root cause analysis for production issues for a fictitious enterprise environment.

https://github.com/open-telemetry/opentelemetry-demo The OpenTelemetry demo repo will be used as the fictitious enterprise 
environment. OpenTelemetry (OTel) Demo is explicitly designed to simulate complex, cascading microservice failures for training 
purposes for training SREs. Trouble shooting these known failures myself will be excellent practice, but runbooks can be 
generated for these known issues as I work through them myself and feed them into the documentation base for retrieval.

Documentation will be generated for this codebase that is a some times outdated, incomplete and of varying quality to simulate a 
challenging modern enterprise environment for an application support team.

The RAG agent will pull from the documentation and code base to work on generating a triage description for incidents: outlining
what information is needed from the user, then making determinations of the problem root causes based on information retrieved.
